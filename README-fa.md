# talking-avatar — اسکیل روتر ویدیوی سخنگوی (تاکینگ‌هد)

ایده: ایجنت‌ها بک‌اند تاکینگ‌آواتار را از روی عادت انتخاب می‌کنند — هر
اسکیل وندوری که نصب باشد، هر پرتره‌ای همان وندور رندر می‌شود. این عادت
پول و زمان هدر می‌دهد. این اسکیل لایه تصمیم است:

**اول پر‌فلایت (اعتبارسنجی عکس و صدا)، بعد انتخاب بک‌اند درست، بعد رندر.**

## چهار بک‌اند

- **sadtalker-local** — رایگان، آفلاین، NVIDIA/CUDA؛ فقط چهره انسانی واقعی
- **sadtalker-cloud-gpu** — همان SadTalker روی GPU اجاره‌ای (کلاس چند سنت)
- **hedra-api** — تجاری، چهره‌های استایلایز را بهتر هندل می‌کند
- **heygen-api** — تجاری، کیفیت استودیویی

## خلأ

بررسی ۲۰۲۶-۱۰-۳۰ با GitHub API: اسکیل‌های موجود تک‌وندورند (HeyGen
رسمی، Creatify، Beatra، پلاگین‌های Hedra)؛ هیچ اسکیل مستقل SadTalker
لوکال و هیچ MCP برای SadTalker وجود ندارد؛ و هیچ‌چیز بین بک‌اندها
**مسیریابی** نمی‌کند. این اسکیل همان خلأ است.

## محتویات

- `skills/talking-avatar/SKILL.md` — قرارداد اسکیل
- `scripts/avatar_route.py` — روتر + پر‌فلایت، فقط استانداردلایب پایتون
- `references/` — ماتریس بک‌اندها، سیم‌کشی TTS فارسی/آلمانی، ۲۰ دام شناخته‌شده
- `mcp-server/` — سرور MCP (سه ابزار)
- `cursor/` — رول Cursor + راهنمای Windsurf/Cline/Continue
- `dist/talking-avatar-skill.zip` — آپلود در Claude.ai
- `tests/` — ۶۰ تست، همه پاس (۲۰۲۶-۱۰-۳۰)
